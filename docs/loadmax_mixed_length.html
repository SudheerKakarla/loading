LoadMax 1D model — variable-length lots along the trailer

This is an extra MIP, not a replacement for the live pad solver. Each row is a one-dimensional strip of usable length \(L\). A lot is an ordered position on that row, not a fixed pad: its length is the length of the pallet assigned to it, from palletLengthDict. Layer 2 uses the same lot and must have the same length. Axles use the lot’s \(x\)-center, not A/B/C/D groups. The pad/slot model is loadmax_model.html.

What is being decided

For each pallet, the model chooses a truck, layer (1 or 2), row (left or right), and lot number \(k\). A lot has no pre-drawn rectangle. Its length comes from the assigned pallet’s palletLengthDict entry. The model packs two independent rows of usable length \(L\), then may stack a same-length pallet on layer 2.

DecisionBinary \(y_{v,l,s,k,i}\) — pallet \(i\) on truck \(v\), layer \(l\), row \(s\), lot \(k\)
Lot length\(\ell_{v,s,k}\) = length of the layer-1 pallet (0 if empty)
EngineHiGHS via scipy.optimize.milp; optional Gurobi twin in container_loading_mixed_length_gurobi.py
Not chosenPallet rotation, trailer width, 2D \(x,y\) placement, A/B/C/D pad groups

Toy. A 48″ pallet on left lot 1 of truck 1 occupies 48″ of the 720″ strip. Lot 2 starts at \(x=48\). A 40″ pallet there occupies 40″ more. Layer 2 on lot 1 may only be another 48″ pallet — not a 40″ one.

Trailer geometry (how \(L\) and the split are built)

The model computes these values before it creates its variables. A-B values below use inches because that CSV stores 48, not 1.2.

\[ \begin{aligned} L &= \texttt{usableLength} \ \text{(or containerLength / trailerLength)} \\ &\quad\text{else}\quad n_{\text{along}} \times \max_i \ell_i, \quad n_{\text{along}} = |\text{unique left-row positions}| \\ k_{\max} &= \max\!\big(1,\ \lfloor L / \min_i \ell_i \rfloor\big) \\ x^\star &= L \cdot \frac{n_{\text{front left}}}{n_{\text{along}}} \\ \text{door zone} &= [L - 2\min_i \ell_i,\ L] \end{aligned} \]

Decision variables

\[ y^{\text{full}}_{v,l,s,k,i} \in \{0,1\}, \quad y^{\text{prtl}}_{v,l,s,k,j} \in \{0,1\} \]

Pallet on truck \(v\), layer \(l\in\{1,2\}\), row \(s\in\{\text{left},\text{right}\}\), lot \(k=1,\ldots,k_{\max}\).

\[ O_{v,s,k} = \sum_{i,j} y_{\cdot,1,s,k,\cdot} \quad\text{(layer-1 occupancy)}, \qquad O^{(2)}_{v,s,k}\ \text{same on layer 2} \] \[ \ell_{v,s,k} = \sum_i \ell_i\, y^{\text{full}}_{v,1,s,k,i} + \sum_j \ell_j\, y^{\text{prtl}}_{v,1,s,k,j} \] \[ x^{\text{end}}_{v,s,1} = \ell_{v,s,1}, \qquad x^{\text{end}}_{v,s,k} = x^{\text{end}}_{v,s,k-1} + \ell_{v,s,k} \] \[ x^{\text{ctr}}_{v,s,k} = x^{\text{end}}_{v,s,k} - \tfrac12 \ell_{v,s,k} \]

Also: lot weight \(W_{v,s,k}\) and stack height \(H_{v,s,k}\) (both layers); binaries \(F_{v,s,k}\) (front) and \(D_{v,s,k}\) (door); extracted front weight \(W^{\text{f}}_{v,s,k} = W_{v,s,k}\, F_{v,s,k}\) (linearised); SKU counters and \(y^{\text{prior}}\) as in the pad model. Empty lots have \(\ell=0\), so they consume no length. A missing lot number is not a physical gap.

Objective — same 4-term fill as the pad model

The model maximises the loading score. HiGHS stores negated coefficients and minimises. Lengths do not affect the score; the score depends on which pallets are loaded.

\[ \begin{aligned} \max \quad &\sum_{v,l,s,k,i} c_v \cdot \pi_i \cdot y^{\text{full}}_{v,l,s,k,i} + \sum_{v,l,s,k,j} c_v \cdot \pi_j \cdot f_j \cdot y^{\text{prtl}}_{v,l,s,k,j} \\ &+ \sum_i \rho\, y^{\text{prior,full}}_i + \sum_j \rho\, y^{\text{prior,prtl}}_j - \lambda \cdot E \end{aligned} \]
SymbolA-BMeaning
\(c_v\)800…300container_priority — preference for earlier trucks
\(\pi_i\)2 if SKU ∈ skuPriorityIncentive, else 1Only membership matters; rank 1/2/3/5 is unused
\(f_j\)leftover / casesFraction of a partial pallet
\(\rho\)2Bonus for loading a prior pallet

Constraints

Each block is one family of rows in the MIP. Pictures are the 1D strip, not the 30-pad map.

1. Demand cap

\[ \sum_{v,l,s,k} y^{\text{full}}_{v,l,s,k,i} \le d_i \qquad \sum_{v,l,s,k} y^{\text{prtl}}_{v,l,s,k,j} \le d_j \]

Upper bound, not a fill requirement. Leftover pallets on the dock are allowed. A pallet longer than \(L\) simply is never placed — the model stays feasible at objective 0.

2. At most one pallet per (layer, lot)

\[ \sum_i y^{\text{full}}_{v,l,s,k,i} + \sum_j y^{\text{prtl}}_{v,l,s,k,j} \le 1 \]

Each truck/row/layer/lot combination holds at most one pallet. The same lot can hold two pallets only when one is on layer 1 and the other is on layer 2.

3. Lot length, weight, and height

\[ O_{v,s,k} = \text{layer-1 assignments}, \qquad \ell_{v,s,k} = \text{layer-1 pallet length} \] \[ W_{v,s,k} = \text{weight on both layers}, \qquad H_{v,s,k} = \text{height on both layers} \]

Unoccupied lots have \(\ell = W = H = 0\).

4. Layer 2 needs layer 1, same length, no stack on a partial

\[ O^{(2)} \le O, \qquad \ell^{(2)} \le \ell, \qquad \ell^{(2)} \ge \ell - L\,(1-O^{(2)}) \] \[ y^{\text{prtl}}_{v,1,s,k,j} + O^{(2)}_{v,s,k} \le 1 \]

Layer 2 needs layer 1 and must have the same length (the same footprint, but not necessarily the same SKU). Nothing can be stacked on a partial pallet. A partial pallet can be placed on a full pallet when the lengths match.

legal

5. Row length capacity

\[ \sum_{k=1}^{k_{\max}} \ell_{v,s,k} \le L \quad \forall v,s \]

Also implied by \(x^{\text{end}}_{v,s,k_{\max}} \le L\) (the variable bound). This is the row-capacity rule. Trailer width is not modelled; the left and right rows are independent strips with the same \(L\).

6. Cumulative position

\[ x^{\text{end}}_{v,s,1} = \ell_{v,s,1}, \qquad x^{\text{end}}_{v,s,k} = x^{\text{end}}_{v,s,k-1} + \ell_{v,s,k} \]

Lots follow one another from the nose. Their \(x\) positions are calculated from the lengths before them; \(x\) is not a separate decision for each pallet.

7. Front / rear by lot center (not A+C / B+D)

\[ x^{\text{ctr}} - x^\star \le L\,(1-F), \qquad x^\star - x^{\text{ctr}} \le L\, F \] \[ W^{\text{f}} \le W,\quad W^{\text{f}} \le \texttt{max\_wt}\, F,\quad W^{\text{f}} \ge W - \texttt{max\_wt}\,(1-F) \]

\(F=1\) means the lot center is on the front side of \(x^\star\) (A-B: 336″). The whole lot weight then counts as front cargo — there is no 0.5 split when a lot crosses the line. At \(x^{\text{ctr}} = x^\star\) both \(F\in\{0,1\}\) are feasible (big-M tie).

8. Door zone and stack height

\[ D=1 \iff x^{\text{ctr}} \ge L - 2\min_i \ell_i \] \[ H_{v,s,k} \le H_{\text{body}} - (H_{\text{body}} - H_{\text{door}})\, D_{v,s,k} \]

A-B: body 9 ft, door 3.5 ft. Typical pallet ~3.8 ft, so door-zone lots are single-layer. The zone is the last two minimum-length pallets (96″ on A-B), not pads 29 and 30.

9. Total weight, axle caps, side / front-back balance

\[ \sum_{s,k} W_{v,s,k} \le \texttt{max\_wt} \] \[ \sum_{s,k} W^{\text{f}}_{v,s,k} \le 19920, \qquad \sum_{s,k} (W_{v,s,k}-W^{\text{f}}_{v,s,k}) \le 22080 \] \[ (1-\tau_{\text{ss}})\, W^{\text{right}}_v \le W^{\text{left}}_v \le (1+\tau_{\text{ss}})\, W^{\text{right}}_v \]

Axle rows are added only when both max_front_wt and max_rear_wt are positive. Side-to-side uses left-row vs right-row lot weights (A-B \(\tau_{\text{ss}}=0.1\)). Front-to-back uses \(W^{\text{f}}\) vs rear; A-B tolerance is 0 so those rows are skipped. Ocean mode turns balancing and axles off.

10. Crushing — heavier below

\[ \text{layer-1 weight} \ge \text{layer-2 weight} \]
legal

11. Compact packing — fill from the nose

When enforce_compact_packing is yes (and the run is not ocean mode), lots are filled from the nose. Unlike the pad model, there is no seed pad 12.

\[ k>1 \Rightarrow O_{v,s,k} \le O_{v,s,k-1} \]

Occupied lots must be \(1,2,\ldots,n\) with no missing lot number. Because an empty lot has length 0, this does not change the physical layout; it keeps one clear numbering for the same packing.

12. SKU penalty, prior bonus, and VDR rules

\[ m_{v,s} = \text{pallets of SKU }s\text{ on truck }v, \quad u_{v,s}\in\{0,1\}\ \text{if } m_{v,s}>0 \] \[ E \ge \sum_v n_v - \texttt{unique\_sku\_n} \quad\text{(HiGHS / original Pyomo; } n_v=\sum_s u_{v,s}\text{)} \] \[ 0 \le y^{\text{prior}}_i \le \min(d^{\text{prior}}_i,\ \text{how many of }i\text{ were placed}) \]

In A-B, unique_sku_n = 31 is fleet-wide in Pyomo (“all containers combined”). The HiGHS mixed-length model uses that fleet total. The Gurobi twin currently checks \(E \ge n_v - 31\) per truck; on A-B this usually makes \(E=0\), so the penalty is dropped. VDR G2/G3/G4 match the pad model and stay off unless --vdr.

Out of scope

  • Two-dimensional packing (width, pinwheel, rotation).
  • A separate free-floating \(x\) decision for each pallet; lot order determines \(x\).
  • Heterogeneous \(L\) per row or per truck.
  • Replacing the live pad MIP (container_loading_highs.py).
  • Hardcoding 1.0 m / 1.2 m — lengths always come from the CSV.
